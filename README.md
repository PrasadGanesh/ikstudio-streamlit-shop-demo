# Shop Sales Dashboard (demo)

Public demo for **Indian Karigar Studio** custom Streamlit dashboard builds.

All numbers in the bundled CSV are **synthetic sample data** (seed 42). Upload your own orders CSV to try the filters.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
